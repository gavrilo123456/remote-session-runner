## P004 scope and gate

Freeze versioned JSON schemas and valid/invalid fixtures for the SSH bridge request/reply frames and mailbox request/response/ACK/event projection. The bridge contract preserves the ten forwarded operation names, request correlation, stable mutation resource IDs and idempotency keys, base64 command output, and a protocol-major check before forwarding. The mailbox contract preserves operation-specific required fields, distinct request/exchange state, response revisions, stable resource IDs, the `not_delivered` boundary without invented target state, event identity/order with UTF-8-or-base64 bytes, and ACK revision/cursor matching.

This phase records schema-level spelling choices where the design leaves frame wrappers open. Schemas and fixtures do not implement an SSH process, mailbox filesystem, handler, or remote execution. Required checks are round-trip fixtures, required-field rejection, and unsupported-major rejection, followed by the full Go test/vet suite and diff checks. P004 has no real-host application test gate; no host/runtime gate is treated as passed.
