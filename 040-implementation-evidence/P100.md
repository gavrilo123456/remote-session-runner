## Implementation and test approach

Route a validated file `run` through the same Mac local API validation, canonical request hashing, idempotency, and durable `run` local-intent acceptance used by `/v1/jobs`. Retain the original stable job/session/command identities on replay. Reconciliation reads only that owner-scoped run intent and any matching local authority job or queued-remote job projection. Publish a terminal response only after the command outcome and teardown are terminal; publish its retained event prefix before the response. If delivery is proven never to have occurred, return the stable intent identities and a `not_created` teardown result without job phase, command state, or event cursor.

The P100 focused tests cover stable acceptance, waiting before authority state exists, terminal command plus teardown publication, and proven non-delivery with no invented target state. P101 owns the complete seven-operation matrix and duplicate-execution retry matrix.
