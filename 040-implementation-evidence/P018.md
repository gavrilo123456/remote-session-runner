## Planned deliverable and gates

1. Register a bounded per-command subscriber before its durable replay query.
2. Replay the requested contiguous range, then hand off buffered live events without gaps or duplicates.
3. De-duplicate by command event sequence, expose the last delivered cursor, and disconnect a slow subscriber on bounded-buffer overflow with a resumable error.
4. Publish only events whose SQLite transaction committed; no runtime process or shell starts in P018.
