## Implementation

- Added a deterministic-clock constructor and `RemoteUncertaintyWindow = 24h` to the remote driver.
- `ReconcileIntent` checks the durable uncertain lifecycle timestamp before every target read. At or after the deadline it returns `ErrRemoteUncertaintyDeadline`, leaves delivery state `uncertain`, and performs no retry or target call.
- Lease renewal cannot extend the deadline because the calculation uses the lifecycle transition into `uncertain`, not mutable lease `updated_at`.
- The expired state remains an indeterminate local outcome for later file-response/recovery phases; this phase does not guess acceptance or rejection.
