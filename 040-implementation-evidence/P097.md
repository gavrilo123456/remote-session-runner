## Scope and implementation decision

The current mailbox command response has no `stdout` or `stderr` preview fields even though the v1 response schema permits them and the designs require optional bounded UTF-8 previews. M-09 explicitly includes a tiny fully-inline result while requiring the event file whenever the available cursor is positive. P097 will add bounded preview projection to active and terminal mailbox snapshots, retaining the event file as the complete ordered source.

The designs specify bounded previews but no numeric limit. This phase selects 4 KiB per stream, clipped only at UTF-8 code-point boundaries. A stream preview is omitted if any retained chunk for that stream is not valid UTF-8. Preview length does not affect command `output_truncated`, event content, cursor, or full-answer status.

Focused assertions will cover M-04 revision progression, terminal immutability after later session-state changes and request-ID reuse, a fresh status request for changed state, and M-09 tiny preview, normal complete output, active snapshot, output truncation, capture-boundary loss, irrecoverable remote gap, and retention expiry. For every response with cursor greater than zero, the test will read the advertised NDJSON file and verify its contiguous lines through the frozen cursor. It will independently evaluate the complete-answer triple and ensure a contiguous `command_lost` event does not claim complete output and a remote gap is not reported as truncation.
