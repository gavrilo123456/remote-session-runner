## Implementation

- Added migration `src/internal/store/migrations/0014_mailbox_exchanges.sql` and advanced the schema ledger to version 14. The table durably binds `request_id`, operation/controller, idempotency key, canonical hash/payload, resource binding, request state, and reserved response revision fields with indexes for key lookup and state recovery.
- Added `src/internal/store/mailbox_exchanges.go` with transactional receipt creation/reload/completion. Reusing a request ID with changed key/hash/payload conflicts; a new request ID with the same operation/controller/key/hash binds to the retained resource/state without a second mutation. Completing one binding propagates the terminal receipt state to equivalent request-ID retries.
- Added `src/internal/mailbox/receipt.go` with `ReceiptProcessor`: it canonicalizes mutation payloads without mailbox correlation fields, records the exchange before the injected handler, resumes an accepted receipt after a simulated crash, and skips already terminal exchanges. It does not publish files or claim exactly-once external side effects.
- Added `src/internal/store/p082_test.go` and `src/internal/mailbox/p082_test.go` covering durable migration/reopen, same-ID conflict, canonical new-ID retry, changed-key conflict, terminal retry state, receipt-before-callback crash recovery, and no second callback for completed exchanges.
