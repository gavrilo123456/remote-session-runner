## Planned deliverable and gates

1. Add a streaming bridge handler for `stream_command_events` that forwards the authenticated controller, command ID, cursor, and optional follow flag to the private runnerd NDJSON endpoint.
2. Convert private event records to versioned bridge `event` frames and a `stream_end` cursor, preserving event order and exact base64 output bytes while rejecting raw output chunks above 16 KiB and bounded serialized event lines.
3. Support reconnect from `after_sequence`, map private 404/403/416/503 and transport uncertainty to structured bridge errors, and reject gaps or malformed private events without fabricating output.
4. Add the server-side multi-frame handler path and fix private runnerd replay errors to return an HTTP error before committing an NDJSON success response.
5. Run focused P054/P049–P054 tests, full Mac hermetic/vet/build/smoke/race/format/diff gates, synchronize and verify Mac/GitHub/Ubuntu equality, then run the named Ubuntu P054 bridge suite. Close evidence only after the host gate passes.

## Unresolved assumptions

- `follow` is an additive optional stream payload field. Omitted means private replay only; `true` requests the private live follow handoff. Both paths end with a bridge `stream_end` once the private stream closes after a terminal event or replay EOF.
- The bridge validates contiguous sequences from the requested cursor and reports `event_history_unavailable` on a gap. It never invents missing events or treats a command exit as SSH transport failure.
- P054 forwards events only. Forced-command deployment, Mac SSH transport, Router mirroring, public HTTPS, and P143 durability approval remain later gates.

## Implementation results

**Status: PASS**

- Added an optional streaming-handler path to the bridge server and forwarded `stream_command_events` through the authenticated controller mapping to the private runnerd NDJSON events route.
- Event replay honors `after_sequence`; optional `follow: true` requests the private live handoff. Private events are converted to versioned `event` frames and a final `stream_end` frame, with contiguous-sequence checks and reconnect-safe cursors.
- Output events preserve the private base64 bytes and are rejected when decoded raw output exceeds 16 KiB or the private byte count is inconsistent. Event lines are bounded before JSON decoding, malformed/unknown private fields fail closed, and sequence gaps produce `event_history_unavailable`.
- Added cursor status mapping for private HTTP 416/410, transport uncertainty, and existing controller/not-found/runtime errors. Private runnerd now resolves replay/subscriber errors before committing a successful NDJSON response, mapping replay gaps to HTTP 416.
- Added schema coverage for the optional stream `follow` field and bridge fixtures for replay/follow, reconnect, multi-frame server output, base64 round-trip, cursor errors, oversized chunks, and gaps.
