## Implementation results

**Status: PASS**

- Added schema migration `0006_exec_jobs.sql` and raised the SQLite schema version to 6.
- Added the durable `exec_jobs` row with stable job/session/command IDs, controller/target/source identity, canonical request bytes and hash, exact script bytes and SHA-256, coordinator phase, command outcome fields, teardown state, and timestamps.
- Added `AuthorityStore.AcceptJob` and `GetJob`. Acceptance validates canonical `run` payload bytes, exact script bytes, stable IDs, and controller/key/hash idempotency in one `BEGIN IMMEDIATE` transaction. Same-key/same-hash retries return the original row; a changed hash returns `ErrIdempotencyConflict`; job/session/command uniqueness collisions return `ErrJobExists` without a second row.
- Added `TestP024...` coverage for `I-04`: durable acceptance, exact payload/script bytes across close and reopen, schema version 6, same-key retry/conflict, pre-insert canonical/script rejection, and stable identity collisions.
