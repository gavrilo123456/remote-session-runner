## Implementation and gate results

- Added the P095 `submit_command` and `get_command` file-mailbox operations. Submission reuses the local API's script, timeout, immutable target, owner, canonical hash, and idempotency validation and records only a Mac-side intent. Reads are owner-scoped and expose local authority or queued-remote projections only through that Mac intent; direct-created commands remain unavailable.
- Added atomic command-plus-event-prefix reads for local authority and remote projections. Active responses freeze their observation time, state, event cursor, and file reference; they do not claim incomplete output was lost. A later snapshot may extend the shared event file, while replay of an earlier frozen response preserves that longer valid file. Terminal snapshots publish the exact stored event prefix before the response.
- Preserved the I-02 boundary: a nonzero shell exit publishes a `complete` mailbox exchange with `command_state=failed` and the actual exit code. Uncertain transport stays `accepted` with no fabricated command state or exit code. Proven non-delivery is rejected without command state or an event file.
