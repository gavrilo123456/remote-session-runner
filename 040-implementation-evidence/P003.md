## P003 scope and gate

Freeze the v1 OpenAPI paths and operation shapes for both owner-only Mac Unix-socket HTTP/JSON and direct Linux HTTPS with mandatory mTLS. Contract fixtures and focused tests must distinguish local-intent acceptance from target-authority acceptance, enforce remote-only direct HTTPS target creation and immutable inherited command targets, and cover the documented session, command, event, cancellation, close, job, and job-read routes. Record stable v1 spellings for response members that the designs leave open. Preserve the same resource and event semantics from P002.

P003 does not implement handlers or runtime behavior and does not define the P004 SSH bridge/mailbox wire formats. OpenAPI must state direct HTTPS mTLS without incorrectly applying that requirement to the local Unix socket. It must not imply the transport-only preflight probe tested Runner. The focused exit gate is route and local/direct contract-fixture tests; this phase will also run the repository Go test and vet suites and `git diff --check` before its scoped commit.
