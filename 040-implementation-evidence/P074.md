## Implementation

- Added migration 0010 with `local_remote_events` and `local_remote_event_cursors`.
- Added `AuthorityStore.MirrorRemoteEvents`, `GetRemoteEventCursor`, and `ListRemoteEvents`. Exact duplicate bytes are idempotent; a conflicting duplicate or non-contiguous sequence aborts the full transaction. Event insertion and cursor advancement commit together, including rollback on an injected cursor-update failure.
- Added `RemoteDriver.MirrorCommandEvents` over the existing bridge stream. It validates event envelopes and bounded output bytes, mirrors each event transactionally, handles stream-end cursors, and preserves the durable cursor on transport/history errors.
- Added focused P074 store and dispatcher tests for deduplication, gaps, conflicting bytes, cursor-commit rollback, stream replay, and no cursor advance on a gap.
