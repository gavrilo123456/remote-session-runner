## Planned deliverable and gates

1. Treat the control completion frame as provisional until both command-scoped FIFOs reach EOF.
2. Bound the output-boundary wait with a configurable grace timeout; close readers and mark the session lost when a descendant or delayed reader retains a pipe.
3. Mark the persistent shell lost when control framing ends unexpectedly, including Bash `exit`, `exec`, or user damage to reserved FD4; refuse all later commands and never create a replacement shell.
4. Exercise delayed pipe retention and all three unsafe shell/control boundary cases.

Required gates: focused P033 tests, store/execution regression tests, full `make test`, `make vet`, `make smoke`, selected-toolchain formatting and `git diff --check`, and the full race suite. P034 owns the combined 100 MiB truncation policy. No host-dependent SSH, HTTPS, mTLS, or Runner application test is assigned to P033. P143's software-crash-only durability path still requires explicit approval if physical power-cut tests are unavailable.
