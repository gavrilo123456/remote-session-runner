## Results

### Implementation

- Added `store.CreateOnlineBackup` and `store.RestoreOnlineBackup` using modernc SQLite's online backup API. Backup uses a same-directory owner-only staging file, validates integrity, foreign keys, schema version, and migration history, syncs the file, and publishes without replacing an existing path. Restore validates the snapshot before modifying the authority, requires the caller to stop services and close other handles, performs an offline restore, checkpoints WAL, reopens, and validates again. A main-database-only copy is never used.
- Added hermetic store tests proving a committed row blocked from checkpoint by an older read transaction is present in the backup and restored authority; restore replaces later target-only data; unsafe paths, existing backup destinations, symlink backups, and corrupt snapshots are rejected; and a rejected corrupt restore leaves the authority unchanged.
- Added an opt-in selected-host Mac gate that starts the actual locald execution composition under `tomasz.walczuk` with fixture-only DB/workspace/socket paths. It creates a ready persistent shell, creates a commit held in WAL and backs it up while locald is live, shuts locald down with the production lifecycle coordinator, confirms the Bash process group is gone, restores only after the service and DB handles have exited, and restarts locald. Reconciliation marked the stale restored ready session lost without reattaching its shell; after confirming the old process group and owner record were absent, the fixture released its retained reservation. A new ready session received a distinct runtime generation. Both service instances shut down cleanly.
- The first actual Mac gate attempt failed because the `t.TempDir` path made the Unix socket path too long for macOS (`bind: invalid argument`). The test-owned socket moved to a short private `/private/tmp/p139-socket-*` directory and the gate passed on rerun. The directory was removed by test cleanup; a follow-up search found no matching leftover directory.
