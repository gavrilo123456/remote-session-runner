## B011-P1 result

Added only these hermetic test files:

- `src/internal/runtime/bug011_persistent_boundary_test.go`
- `src/internal/execution/bug011_boundary_contract_test.go`

The persistent-shell fixture uses a temporary `0700` workspace and a
test-owned short-lived child. Its narrow injected inspector can observe only
the child PID written by that fixture; it does not inspect the installed
service or system-wide process table. It proves:

1. a normal `false` result completes with exit code one and leaves the shell
   usable;
2. sourced `set -e; false` exits the persistent Bash before a completion
   frame, leaves the capacity boundary retained, and rejects later work; and
3. a background child that holds the command output pipe causes
   `ErrOutputBoundary` while the persistent Bash remains alive.

The execution fixture proves that both persistent-shell boundary errors become
truthful incomplete `lost` command/session records, retain the matching slot
and reservation, and cannot be sourced again through a later scheduler resume.
Its four-retained-lost plus one queued-one-off fixture proves that partial,
extra-direct, missing-terminal-event, and mismatched inventory shapes fail
before runtime proof, capacity release, or command execution. No script is
replayed.
