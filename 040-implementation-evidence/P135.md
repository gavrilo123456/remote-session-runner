## Scope and gate

- Plan deliverable: exercise `runner-locald`/`runnerd` and their agent/Bash runtime across executor death with a known surviving child.
- Focused exit gate: P135 `F-01` executor/shell subset; prove the old shell is not reattached and no replacement shell executes queued work.
- Target machines: Mac `tomasz.walczuk` on macOS and designated Ubuntu `ubuntu` on `oracle-yuta-konopka-ubuntu-micro-02`. Each host test will use a test-owned SQLite database, workspace, and Unix socket; it will not restart or mutate the installed shared service. Temporary fixtures must be removed after child processes exit.
- Initial code finding: `execution.Service.ReconcileStartup` exists but neither daemon calls it before opening its API. The host adapters keep process/workspace ownership only in memory, so a fresh executor cannot reconcile a known surviving shell. The private socket listener also rejects any pre-existing socket, including its own stale socket after SIGKILL. These are in-scope gaps surfaced by P135's restart gate and must be repaired rather than waived.
- Planned implementation: persist and validate owner-only runtime ownership records for both adapters; quarantine and stop the previous process group without shell reattachment; wait for the whole known group, not just its Bash leader, before confirming cleanup; run startup reconciliation before either executor reports ready; and safely remove a stale owner-owned Unix socket while refusing a live/replaced path. Add real-process restart tests for both target hosts and assertions on durable session/command state, process identity, cleanup, and no second execution.
- Planned gates: focused P135 tests on Mac and Ubuntu; `make test`, `make vet`, `make build`, `make smoke`, D-12 import-boundary test if package imports change, race-enabled tests for changed concurrency paths, formatting, and `git diff --check`. Host tests are separate and opt-in; a skip is not a pass.
- No unresolved design choice changes the PoC. Runtime manifests contain process lifecycle metadata only and are owner-only host state, never credentials or command content. If a host test cannot establish its process/socket fixture safely, record `NOT RUN`/`FAIL` and stop before the next phase.

## Results

### Implementation inventory

- Added an owner-only, synced process-ownership record for each real runtime, including host OS, session/generation, workspace ownership, OS account, PID/process group, executable, and stable process start identity. Records are validated before recovery and contain no script, output, or credential data.
- Mac uses the kernel birth timestamp reported by `libproc`; Linux uses `/proc` process start identity. Both adapters persist group identity before accepting work, verify it while running, and on executor restart stop only the recorded account-owned process group, wait for it to disappear, clean its owned workspace, and never reattach the old shell. Unconfirmed cleanup remains conservative.
- Both daemons run startup reconciliation before opening their listeners or reporting ready. Private Unix listeners can remove only an owner-owned stale socket after a failed connection probe and same-file recheck; active, replaced, non-socket, or foreign paths remain untouched.

They require the Mac account `tomasz.walczuk` and Ubuntu account `ubuntu` on the designated host, verify the known surviving child is gone, durable running work is lost, queued work is rejected, and no replacement shell runs it.
