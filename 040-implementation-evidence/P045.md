## Implementation results

**Status: PASS**

- Extended `LinuxRuntimeOptions` with immutable approved repository aliases and an optional owner-only credential reference.
- Added `LinuxSourceRequest`, `LinuxResolvedSource`, and `LinuxProcessAdapter.PrepareSource`. Empty sessions retain the existing private workspace behavior; `git_revision` accepts only an approved absolute local path or HTTPS alias.
- Git preparation resolves the requested moving branch to one exact 40-character commit, clones without local object links, checks out detached, persists `core.hooksPath=/dev/null`, and verifies the checked-out `HEAD` before the session is startable.
- Git commands disable system/global config and terminal prompts. If a credential reference is configured, Git receives a temporary host-side askpass helper; the credential file is never copied into the workspace or exported to the persistent session shell. The same-account `ubuntu` limitation remains explicit.
- Preparation errors remove the owned workspace. Cleanup removes a successfully prepared Git workspace through the normal adapter path.
- Added `src/internal/runtime/p045_test.go` with alias/credential validation and the real Linux fixture. The host fixture moves the source branch after preparation and proves the session still runs the original commit/content, checks the hook tripwire and persisted hook policy, verifies the credential secret is absent from the session environment, and confirms workspace cleanup.
