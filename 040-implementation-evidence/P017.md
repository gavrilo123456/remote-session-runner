## P017 deliverable

1. Add a bounded event append API that verifies sequence continuity, preserves raw output bytes and byte counts, rejects appends after terminal state, and never allows a second sequence-1 event.
2. Add cursor-based replay that returns only a contiguous durable event range after a caller sequence, with a gap error rather than a successful partial stream.
3. Add command state transitions that validate the domain transition, append the matching lifecycle/terminal event, update state and terminal `final_event_sequence`/output flags, and commit the event and state together. The internal `cancelling` state has no separate v1 wire event; its durable state change remains in the transaction and its terminal event closes the stream.
4. Keep P018 subscriber fan-out, P019 scheduler/slots, and P020+ runtime behavior outside this phase. No process or shell starts here.
