## Scope and planned gate

P009 implements a pure canonical JSON encoder, a versioned SHA-256 request hash, and an idempotency comparison. The comparison is a match only when both the canonicalization version and digest match; every differing digest or version is a conflict. It does not add persistence, mailbox import behavior, API handlers, or an execution path.

The canonical JSON v1 contract will sort object keys, preserve array order and string code points, normalize JSON numeric spelling, reject malformed/ambiguous JSON, and apply explicitly supplied resolved defaults before encoding. The top-level mailbox correlation `request_id` and lookup `idempotency_key` are not mutation payload. The P004 contract explicitly defines an omitted session/job `source` as `{"mode":"empty"}`, so that omission will hash identically to the explicit default. Environment/config-dependent values such as a default timeout are not fixed by the wire schemas; callers must pass their resolved values as defaults rather than this pure domain helper guessing them. The P009 tests will identify the canonicalization version and use fixed golden hashes.

Added `src/internal/domain/canonical.go` and `canonical_test.go`. The pure helper canonicalizes an operation plus a validated request body, checks an optional body operation agrees with the caller's route/frame operation, excludes top-level exchange `request_id` and lookup `idempotency_key`, and adds the design-defined empty source for create/run requests when omitted. Config-dependent top-level defaults are supplied after validation; nested defaults must already be materialized by the caller. Canonical JSON v1 sorts object keys, preserves array order and UTF-8 code points without Unicode normalization, normalizes exact decimal number spellings without float64 conversion, and rejects duplicate keys, trailing values, malformed JSON, invalid UTF-8, and unpaired Unicode surrogates. The SHA-256 input includes a v1 domain separator. `CanonicalHash` exposes its version and a copied digest for storage; `CompareIdempotency` matches only equal versions and digest bytes.
