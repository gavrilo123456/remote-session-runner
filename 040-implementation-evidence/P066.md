Relevant design/plan facts confirmed:

- P066 is Mac ingress only; the Unix handler must not load SSH credentials or dial the remote host.
- Cancel is an idempotent request keyed by the command ID. Close is a keyed session request whose policy is part of the canonical request hash; the local API acknowledges intent recording and does not claim teardown completion.

- Remote queued cancel/close requests remain local intents until later Router delivery; local authority state is not fabricated by this phase.
