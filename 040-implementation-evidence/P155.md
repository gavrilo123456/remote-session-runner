- `TestP155MacInstalledMultiInboxMailboxGate`, which uses the native

preflights both complete mailbox directory trees before publishing either
request, uses the same client-visible request/idempotency identities in both
roots, and requires a complete untruncated/gap-free terminal event boundary.
