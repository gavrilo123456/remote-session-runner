## Implementation

- `runner-locald` now returns a target-authority acceptance envelope when `RunJob` has already committed a job row but teardown reports an unconfirmed/lost outcome. The job phase, session state, and command result remain readable, so the Mac Router does not classify delivered work as never delivered.
- The SSH bridge run adapter preserves a structured runnerd job result even when runnerd uses a non-2xx status for a teardown error. Ordinary private API errors still use the existing typed bridge error mapping.
- The Mac local API now reads a local authority `exec_jobs` row after an accepted local queued run and exposes the durable phase, command result, teardown state, stable IDs, and local authority metadata. Recorded, uncertain, and proven-never-delivered intents without an authority row remain `view: local_intent`; no target state is fabricated.
- Added focused P079 tests for locald teardown failure and stable retry without a second command/stop, bridge preservation of a lost job result on a private error status, local authority job reads, and proven-never-delivered job reads. Existing P024–P078 tests continue to pass.
