## Implementation

- Added migration `src/internal/store/migrations/0015_mailbox_response_revisions.sql` and advanced the schema ledger to version 15 with current response bytes/hash columns alongside the P082 terminal snapshot fields.
- Extended `src/internal/store/mailbox_exchanges.go` with `PublishMailboxResponse`. Nonterminal publications increment `response_revision`; terminal publications freeze bytes, SHA-256, revision, and available event cursor. Identical terminal replay is idempotent; changed terminal bytes/cursor or post-terminal nonterminal publication returns `ErrMailboxTerminalImmutable`.
- New request IDs bound to the same key/hash inherit current and terminal response snapshots. Reload validates response and terminal hashes and cursor bounds, so a corrupted snapshot is rejected before use.
- Added `src/internal/store/p083_test.go` covering revisions 1→2→terminal, exact terminal replay, changed/post-terminal rejection, and new-ID inheritance of the immutable terminal snapshot.
