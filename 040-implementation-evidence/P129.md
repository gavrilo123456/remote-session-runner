## Contract and scope

- Implement bounded, low-cardinality operational measurements for live session/command slots, queued commands/intents, dispatch attempts, reconciliation age, event lag/gaps, output truncation, storage errors, cleanup failures, and mailbox backlog.
- Expose metrics safely alongside operator health/doctor output. The direct public listener remains behind mandatory mTLS; no secret, raw command, resource ID, or per-user label may appear in the metrics surface.
- Log threshold transitions with stable metric names and values; avoid repeated log spam while a threshold remains exceeded.
- Threshold defaults must be explicit and documented. Measurements of live host state must come from the authority or mailbox, never preflight assumptions.
- Host validation is still required on Mac `tomasz.walczuk` and Ubuntu `ubuntu` after the implementation commit is pushed and both clean checkouts match.
