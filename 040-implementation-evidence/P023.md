## Planned deliverable and gates

1. Add a fake-clock policy sweep over authoritative sessions and commands.
2. Keep idle expiry active only for `ready` sessions with no authoritative queued, running, or cancelling command; accepted queued work waiting for host capacity pauses idle expiry, and active commands are never idle-expired.
3. Enforce command timeout from the running command timestamp and the independent session maximum lifetime from `expires_at`; confirmed stop/teardown records `timed_out`/`expired` and releases capacity, while any uncertain cleanup records `lost` and retains the affected reservation/slot.
