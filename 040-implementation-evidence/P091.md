## Implementation and gate results

- Added schema migration 17 with persisted terminal-response cleanup deadlines, restart-safe response cleanup claims, durable response-to-command event-file references, and event-file cleanup claims. Existing P016 terminal responses derive the original seven-day deadline from terminal publication, capped by `acknowledged_at + 24h` when already acknowledged.
- A valid first ACK moves cleanup earlier only when its 24-hour deadline precedes the existing seven-day deadline. A late ACK records receipt without extending an elapsed deadline. Projectors refuse to recreate an expired or claimed response.
- Added owner-only, directory-synced response/event unlink operations and `ArtifactCleaner`. It removes one response after its deadline and removes a shared command event file only after the command is terminal and every durable response reference has expired. Cleanup claims make a crash between SQLite and unlink safe to retry. A later new status response within normal event retention can rebuild an event file after cleanup.
- `Projector.PublishCommand` verifies the response's command ID and event-file path before recording the reference and publishing the event prefix. The per-command file remains shared across request IDs.
