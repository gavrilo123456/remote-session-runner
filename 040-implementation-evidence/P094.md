## Implementation and gate results

- Added `mailbox.SessionProcessor` for the P094 create/get slice. It commits each mailbox receipt before invoking the local session-operation boundary, atomically persists response revisions, publishes through the synced outbox, removes the inbox pair only after the response is durable, resumes accepted create responses after restart, and advances them only after a local authority or remote projection reaches a known ready/terminal boundary. A proven `not_delivered` outcome is rejected without a session state; an unresolved/missing snapshot stays accepted.
- Refactored local API session create/read logic into reusable owner-scoped helpers. The local API server implements the mailbox operation boundary in process without creating a Unix-socket client or making an HTTP/network call. Session reads preserve queued local intents, read eligible remote projections, and expose a local authoritative session only when its accepted local intent matches the immutable target/controller. Direct-created resources without a Mac intent remain inaccessible through Mac mailbox reads.
- Fixed response correlation on a new-ID same-key retry: the stored prior result is copied with the new `request_id`, and the copied response hash is recalculated. The P083 regression now verifies the retry's terminal snapshot remains immutable and correlated to its own request ID. Added an ordered accepted-exchange query so the session processor can resume pending creates.
