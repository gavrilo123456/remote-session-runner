## Planned deliverable and gates

1. Extend the P050 bridge forwarder for `submit_or_resume_command` and `get_command` only.
2. Preserve the bridge frame's stable `resource_id` as the private `command_id`, forward the same `idempotency_key`/request ID, preserve exact decoded script bytes, and derive controller query/body identity only from the authenticated server-side mapping.
3. Map private runnerd JSON responses and HTTP errors into bridge result/error replies without treating shell exit state as an SSH/transport exit status.
4. Add fake submit/read/retry/error fixtures, script-byte and timeout/ordinal coverage, and an owner-only Unix-socket request fixture.
5. Run P051 focused tests, full Mac hermetic/vet/build/smoke/race/format/diff gates, then synchronize and run the named Ubuntu host suite.

## Unresolved assumptions

- The bridge payload's `session_id` identifies the already accepted remote session; the target is inherited and cannot be overridden by command forwarding.
- `resource_id` is the stable private `command_id`; `intent_ordinal` and optional `timeout_seconds` are operation payload fields. No bridge code infers IDs or target from script content.
- P051 forwards submit/read only. Job, cancel/close, and event forwarding remain P052–P054.

## Implementation results

**Status: PASS**

- Extended `RunnerdForwarder` for `submit_or_resume_command` and `get_command` only.
- Submit forwarding preserves the bridge `resource_id` as `command_id`, `session_id`, `intent_ordinal`, optional timeout, exact decoded script string, idempotency key, and request ID. The controller body is generated only from the authenticated server-side key mapping. The target is inherited from the named session; no target override or script-derived routing exists.
- Command reads use the private runnerd command route and mapped controller query parameters. Private command results remain result payloads even for shell exit code 1; transport uncertainty remains a protocol error and is never represented as an SSH/command exit status.
- Added stable submit retry body/reply fixtures, mapped identity checks, failed-command exit-state coverage, oversize-script rejection before HTTP forwarding, and retained the owner-only Unix-socket fixture.
