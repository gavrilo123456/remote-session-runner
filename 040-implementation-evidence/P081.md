## Implementation

- Added `src/internal/mailbox/importer.go` with an owner-only `root/inbox` setup, marker-last discovery, safe request-ID/basename validation, 0600 regular-file checks, symlink rejection, bounded reads, strict single-JSON decoding, embedded v1 request-schema validation, filename/request-ID correlation, and the shared domain 1 MiB serialized-request and 128 KiB UTF-8 script limits.
- The importer ignores every unmarked draft and calls an injected handler only for an accepted request. Rejections are returned as bounded diagnostic results without exposing script bytes. Inbox pairs remain in place for P082 durable receipt/import handling; P081 does not execute Runner mutations, delete files, or publish responses.
- Added `src/internal/mailbox/p081_test.go` covering marker-last ordering, exact raw-byte delivery, unsafe names, request/marker symlinks, non-regular files, wrong modes, partial JSON, schema/unknown-field rejection, filename/request-ID mismatch, request-size overflow, script-size overflow, and the existing mailbox schema contract.
