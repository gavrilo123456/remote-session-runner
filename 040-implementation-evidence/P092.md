## Implementation and gate results

- Added migration 18 with a separate response-reference/cleanup pair for Mac-mirrored remote commands; migration 17's foreign keys continue to protect local authoritative commands. Terminal response publication now creates the appropriate reference in the same SQLite transaction when its stored response advertises an event file and positive cursor.
- Garbage collection now marks normal command output expired immediately for fresh reads while retaining event rows referenced by any mailbox response whose cleanup deadline is still in the future. This applies to both `exec_command_events` and Mac `local_remote_events`. Mirrored remote output also expires from its terminal event or confirmed gap time; ordinary remote event reads fail as unavailable, and later remote projection updates cannot revive already expired output.
- Added a response-scoped event read that verifies the exact mailbox request, command reference, frozen cursor, and live cleanup deadline. `Projector.PublishCommand` uses it to rebuild a missing/corrupt event file after ordinary output expiry; the read does not change `ListCommandEvents` or fresh terminal snapshots, which still report `retention_expired` with cursor zero/no event file.
