## Planned deliverable and gates

1. Replace the P031 per-command output files with fresh private stdout/stderr FIFOs, opened before dispatch and drained concurrently so one full stream cannot block the other.
2. Preserve arbitrary raw bytes, retain separate stream identity and drain order, bound each emitted chunk to 16 KiB, and flush partial data on a normal-load interval near 50 ms.
3. Keep the P030 control FD separate from both output streams and retain the P031 persistent Bash state contract.
4. Exercise binary bytes, 40 KiB output chunking, concurrent stdout/stderr collection, and a delayed two-byte flush case.

Required gates: focused P032 tests, store/execution regression tests, full `make test`, `make vet`, `make smoke`, selected-toolchain formatting and `git diff --check`, and the full race suite.
