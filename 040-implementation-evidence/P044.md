## Implementation results

**Status: PASS**

- Added `src/internal/runtime/p044_test.go` with the same adapter-level suite for Mac and Linux host-process adapters.
- The shared suite verifies persistent Bash state across sourced scripts: working directory, exported and local variables, alias, function, and `umask` state. It also verifies a nonzero command result (`return 7`) preserves stdout/stderr and keeps the shell usable.
- Unsafe-boundary cases cover `exit`, `exec`, reserved control-FD closure, and a delayed reader that leaves a background pipe writer. Each case loses the persistent shell and the next command is rejected; no replacement shell is started.
- The delayed-reader case uses the adapter's default one-second output-boundary timeout and requires `ErrOutputBoundary` followed by `ErrPersistentShellLost`.
