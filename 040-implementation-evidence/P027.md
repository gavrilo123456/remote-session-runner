## Planned deliverable and gates

1. Add an optional generation-aware runtime reconciliation seam that reports the observed runtime generation and confirmed cleanup without permitting shell reattachment.
2. Reconcile persisted `creating` sessions to `failed` after confirmed partial-runtime cleanup or to `lost` when cleanup is uncertain.
3. Reconcile persisted `ready`/`busy` sessions to `lost`, preserve already committed terminal command outcomes, mark active commands `lost` with incomplete output, reject queued work behind the unusable session, and retain command/session capacity until cleanup is confirmed.
4. Resume persisted `closing` sessions to `closed` only after confirmed cleanup; otherwise settle them as `lost`.
5. Add focused fake-runtime tests for generation mismatch, residual slot retention, creating cleanup outcomes, closing recovery, and proof that restart never calls `StartAgent` or `ExecuteCommand`.

Required gates: focused P027 and P025–P027 execution tests, store/execution tests, full `make test`, `make vet`, `make smoke`, selected-toolchain formatting and `git diff --check`, and the full race suite. No host-dependent runtime, SSH, HTTPS, mTLS, or Runner application test is assigned to P027. P143's software-crash-only durability path still requires explicit approval if physical power-cut tests are unavailable.

## Implementation results

**Status: PASS**

- Added `RuntimeReconciler`, generation-aware reconciliation request/result types, and `Service.ReconcileStartup`.
- Persisted `creating` sessions now become `failed` after confirmed cleanup or `lost` after uncertain cleanup; confirmed cleanup releases the session reservation.
- Persisted `ready`/`busy` sessions never reattach. Active commands become `lost` with `OutputComplete=false`, queued commands become `rejected`, and uncertain command/session reservations remain live. A reported generation mismatch is counted explicitly.
- Persisted `closing` sessions become `closed` only after confirmed cleanup and release their reservation; otherwise they become `lost`.
- Added P027 fake-runtime tests covering confirmed and uncertain creating cleanup, busy restart with generation mismatch/residual slot, closing recovery, queued rejection, idempotent terminal retry, and no calls to `StartAgent` or `ExecuteCommand` during reconciliation.

The implementation commit was `faf5b619d269599c0fa42c78196222509e22da39` (`phase(P027): reconcile startup sessions without shell reattachment`).
