## Planned deliverable

- Add schema migration `0008_local_intents.sql` and raise the schema version.
- Persist operation/resource identity, immutable target/source/controller metadata, canonical request hash/version, idempotency key, full request payload, exact script bytes/hash, optional command ordinal, delivery state, lease/attempt metadata, and timestamps.
- Record an immutable intent lifecycle entry for the initial local requested/recorded state.
- Reload and validate the exact payload after a store restart; reject tampered payload/script bytes before any execution path exists.

P058 owns local idempotency retry/conflict transactions. P059 owns command ordinals, leases, eligibility, and recovery queries. P060 owns `runner-locald` acceptance and its private socket. This phase does not implement those later boundaries.

P143 remains a future approval gate: if physical power-cut testing is unavailable, a software-crash-only durability claim requires explicit user approval and must not be assumed from this phase.
