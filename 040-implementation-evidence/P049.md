## Planned deliverable and gates

1. Implement version-1 request/reply frame types and strict NDJSON codec over `io.Reader`/`io.Writer`.
2. Enforce the shared one-MiB serialized-frame limit before JSON decoding, including a no-newline oversized record and a malformed oversized record.
3. Map the authenticated server-side key to an immutable `domain.ControllerIdentity`; reject forged controller fields from frame JSON and do not infer identity from payload.
4. Handle only local `hello` and `ping` in this phase. No runnerd forwarding or shell/process logic belongs in P049; later P050–P054 add forwarding operations.
5. Add frame fuzz coverage and focused protocol tests, then run the full Mac hermetic/vet/build/smoke/race/format/diff gates and the named Ubuntu host gate after synchronized delivery.

## Unresolved assumptions

- The authenticated key argument is the server-side SSH key fingerprint/principal selected by the forced-command layer; it is never read from request JSON.
- Protocol version `1` is the current major. Unknown versions fail closed before dispatch; additive payload fields remain opaque to this framing layer and are validated by the later operation handlers.
- A malformed or oversized frame is a protocol error and is returned by the codec without invoking any handler. `hello` and `ping` are answered locally and never forwarded.

## Implementation results

**Status: PASS**

- Added `src/internal/sshbridge/protocol.go` with version-1 request/reply envelopes, operation vocabulary, strict unknown-field handling, bounded NDJSON decoding, bounded reply encoding, local `hello`/`ping`, and protocol/error values.
- The decoder uses a fixed maximum-plus-terminator backing capacity and `bufio.Reader` chunks. It checks the raw frame limit before JSON decoding, accepts a final frame without a newline, and rejects an oversized frame before attempting malformed JSON decoding.
- Added `KeyControllerMap` and `Server`. The server resolves the immutable controller only from the authenticated server-side key argument, rejects controller/principal fields in payload JSON, and never forwards `hello` or `ping`. Non-handshake forwarding remains absent until P050–P054.
- Added focused tests for local handshake replies, no-forward behavior, unsupported operations, unknown protocol major, top-level/nested forged controller fields, additive payload fields, no-newline oversize, malformed oversize pre-decode ordering, bounded framing, and fuzz-seed execution.
