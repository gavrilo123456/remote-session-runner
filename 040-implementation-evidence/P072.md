## Implementation

- Added remote submit readiness gating in `RemoteDriver`: a recorded or in-flight same-session create intent leaves the command recorded and unclaimed; only a target-reported `ready` session permits the submit mutation.
- Create acceptance and reconciliation capture a validated `session_state`; the driver refreshes non-ready sessions through the existing stable `get_session` bridge read and never treats a missing or malformed readiness result as permission to send.
- A terminal create state or proven create non-delivery marks a dependent recorded command `not_delivered` with `remote_session_create_failed`; no command bridge mutation or replacement resource is created.
- Existing commands for pre-existing sessions without a local create intent retain the established dispatch path. The new gate applies when this controller has a recorded create intent, while durable event/projection state remains assigned to later phases.
- Added P072 focused tests for creating-to-ready polling, failed-create dependent non-delivery, and direct early-submit race safety.
