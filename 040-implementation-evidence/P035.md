## Planned deliverable and gates

1. Track one active command and expose a bounded `CancelCurrentCommand`/`StopCommand` seam with an explicit grace period.
2. Interrupt the process group, wait for control plus output EOF confirmation, and return `Confirmed=true` only when the persistent shell remains reusable; otherwise return `ErrPersistentShellLost` and prevent replacement execution.
3. Preserve the command's actual nonzero result after a confirmed clean stop; never fabricate a cancelled terminal result from an unproven signal.
4. Exercise direct interruption, delayed descendants, bounded timeout, and no replacement shell.

Required gates: focused P035 tests, store/execution regression tests, full `make test`, `make vet`, `make smoke`, selected-toolchain formatting and `git diff --check`, and the full race suite. P036 owns descendant inspection/cleanup and retained capacity for uncertain residual processes. No host-dependent SSH, HTTPS, mTLS, or Runner application test is assigned to P035. P143's software-crash-only durability path still requires explicit approval if physical power-cut tests are unavailable.
