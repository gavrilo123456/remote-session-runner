## Implementation and Mac gates

- Added `src/internal/store/migrations/0009_local_idempotency.sql` and raised `CurrentSchemaVersion` to `9`.
- Extended local intent acceptance with an atomic local idempotency binding. The transaction looks up the retained `(controller_type, controller_id, operation, idempotency_key)` record, returns the original intent for the same canonical hash, rejects a changed hash with `ErrIdempotencyConflict`, or inserts the intent, initial lifecycle row, and binding together.
