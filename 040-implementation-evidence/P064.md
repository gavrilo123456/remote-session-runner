## Planned deliverable and gates

- Add `POST /v1/sessions/{session_id}/commands` and `GET /v1/commands/{command_id}` to `src/internal/localapi`.
- Resolve the parent only from the owner-scoped Mac `create_session` intent. A direct-created authoritative session is not visible to this ingress and must be denied.
- Reject any caller attempt to supply or override `execution_target`, controller, source, or session identity. Inherit all immutable values from the session intent and record a `submit_command` local intent with a locally allocated ordinal.
- Enforce serialized request bytes before decode/store and `domain.MaxScriptUTF8Bytes` before intent insertion. Preserve exact script bytes and canonical request hash/idempotency behavior.
- Focused gate: oversize script leaves no command intent; Mac command acceptance/read and direct-created denial; no SSH loader/dialer dependency.

P143 remains a future explicit approval gate if physical power-cut testing is unavailable; this phase cannot infer that approval or durability result.

## Implementation result

- Extended `src/internal/localapi/server.go` with `POST /v1/sessions/{session_id}/commands` and `GET /v1/commands/{command_id}`.
- Submit resolves the parent only through the owner-scoped Mac `create_session` intent. Direct-created authoritative sessions are invisible to this ingress and return `session_not_found`; no direct authority command is created.
- The command request accepts only `script` and optional positive `timeout_seconds`. Strict decoding rejects caller-supplied target, controller, source, or session identity fields. Target, environment, source, and controller are copied from the committed session intent.
- The handler enforces the 1 MiB serialized body ceiling before decode, validates UTF-8 and the 128 KiB script ceiling before `AcceptLocalIntent`, canonicalizes the session/script/timeout payload, and records a `submit_command` local intent with a durable per-session ordinal.
- Command acceptance returns `acceptance_scope: local_intent` and `known_state.delivery_state: recorded`; command reads return `view: local_intent` without fabricated command state or output.
- Added focused tests for local and queued-remote targets, inherited immutable fields, exact script bytes, ordinal allocation, idempotency replay, forged target rejection, oversize-before-insert, direct-created denial, and no authoritative command insertion.
