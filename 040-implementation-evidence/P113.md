## Baseline findings

- `directHTTPSAPI.ServeHTTP` routes command GETs to `handleGetCommand`; it has no `/v1/commands/{id}/events` route.
- The private runnerd and local APIs already use the shared `ExecutionService` replay method and serialize public events as bounded NDJSON records.
- `AuthorityStore.ReplayCommandEvents` validates sequence continuity, but returns an empty successful result when `output_unavailable_reason` is `retention_expired`. A direct handler that only streams that result could falsely return 200 for an expired history.
- The runtime caps raw output chunks at 16 KiB; the shared serialized-frame ceiling is 1 MiB. The event API must bound each encoded line and reject a broken/gapped/expired range before writing a successful response.

## P113 scope and gates

Implement the direct HTTPS finite replay path, mapped-controller ownership check, strict cursor/query validation, public P002 command-event NDJSON shape, and structured `410 event_history_unavailable` responses for expired or gapped history. Verify that replay after a cursor returns only the contiguous suffix and that expired history never produces a successful partial/empty stream. Bound each serialized event line before writing it.

P113 does not implement follow/subscription or overflow recovery; those remain P114. No public endpoint or temporary TLS probe is used as an application test. The focused gate is the P113 direct subset of I-03.

## Implementation and validation record

The missing direct `/events` handler is implemented for finite replay. It requires the mapped `direct_mtls` controller, validates the path and cursor/query, reads via the shared execution service, and serializes the P002 event shape as bounded NDJSON. Each output payload is capped at the runtime's 16 KiB chunk size and each encoded line is checked against the 1 MiB frame limit before success headers are written. The response advertises `X-Runner-View: authority` and `X-Runner-Stale: false`.

The store previously returned empty success for expired replay and read the retention marker separately from event rows. Replay now reads command metadata and events from one deferred SQLite snapshot, returns a distinct retention-expired error, and verifies a terminal range reaches its final sequence. Direct replay converts gaps and expired history to `410 event_history_unavailable` with `output_complete: false` and the appropriate unavailable reason; malformed cursors/query fields return 400. The local and private adapters map the new store expiry error to their event-history failure status as well. `follow=true` is deliberately deferred to P114.
