## Planned deliverable

- Allocate a missing `submit_command` `intent_ordinal` under the same immediate transaction as intent/idempotency creation; preserve explicit ordinals and the existing unique `(session_id, intent_ordinal)` constraint.
- Add ordered eligibility queries that never release a later command ahead of an earlier unsettled command in the same session.
- Add owner-bound lease claim and renewal transactions with attempt counts, expiry checks, and lifecycle history for claims; add recovery queries for expired dispatching/uncertain work without automatically resubmitting uncertain mutations.
- Cover concurrent ordinal allocation and a lease-renewal/claim race.

P060 owns `runner-locald` target acceptance and private socket checks. This phase does not run a shell or make a remote application claim.

P143 remains a future approval gate: if physical power-cut testing is unavailable, a software-crash-only durability claim requires explicit user approval and must not be assumed from this phase.

## Implementation and Mac gates

- Extended `AcceptLocalIntent` so a new `submit_command` with no caller ordinal allocates the next per-session `intent_ordinal` inside the same `BEGIN IMMEDIATE` transaction as the intent and local-idempotency binding. The existing unique `(session_id, intent_ordinal)` constraint remains the database backstop.
- Added `ClaimLocalIntent` and `ClaimNextLocalIntent`. Claims select only recorded, unleased/expired intents, enforce that earlier unsettled command ordinals block later commands, increment `attempt_count`, set owner/expiry, move to `dispatching`, and append one lifecycle entry atomically.
- Added owner-bound `RenewLocalIntentLease` with expiry and state checks. A wrong owner or expired lease returns `ErrLocalIntentLeaseLost`; renewal does not mutate immutable request bytes or append a false state transition.
- Added `ListEligibleLocalIntents` and `ListRecoverableLocalIntents`. Recovery reports expired `dispatching`/`uncertain` work without silently changing it back to recorded or resubmitting an uncertain mutation.
- Added `src/internal/store/p059_test.go` covering concurrent ordinal allocation, ordered predecessor blocking through `accepted` until `reconciled`, and a two-owner lease claim/renewal race with expiry recovery.
- Focused Mac gate: `go test ./src/internal/store -run '^TestP05[789]' -count=1` — PASS.
- Mac repository gates: `make test` — PASS; `make vet` — PASS; `make build` — PASS; `make smoke` — PASS; `go test -race ./...` — PASS; `git diff --check` — PASS.
- No Router, SSH, shell, or target-authority acceptance path was added. Lease and recovery states are local delivery metadata.
