## Planned deliverable and gates

1. Add a Linux process adapter that prepares an owner-only per-session workspace below the doctored workspace root and records immutable session/generation ownership.
2. Start the existing shared persistent Bash implementation as the selected `ubuntu` account, expose the shell for later execution phases, and inspect its actual PID/UID/command.
3. Close the shell and remove only adapter-owned workspaces; prepared local paths are not introduced and no workspace confinement claim is made.

Required gates: focused P040 unit and real-Linux process tests, store/execution regression tests, full `make test`, `make vet`, `make smoke`, selected-toolchain formatting and `git diff --check`, and the full race suite. The Ubuntu test must run only after the Mac implementation is pushed and the Ubuntu checkout is fast-forwarded to the same commit. P040 does not claim full P-LNX-01 descendant/restart/policy coverage, HTTPS/mTLS, SSH-bridge, or two-host Runner application acceptance.
