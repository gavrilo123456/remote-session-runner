## Implementation

- Added `src/internal/dispatcher/remote.go` with a lease-owning remote driver over the existing `sshbridge.RequestFrame` and `sshclient.Client` contracts.
- Frames use the committed intent ID as the stable bridge `request_id`, the committed resource ID and idempotency key, and the committed submit ordinal. Payloads are reconstructed from the immutable SQLite payload and exact persisted script bytes; no replacement IDs or caller payload are generated.
- The complete bridge operation set is covered for remote create, submit, cancel, close, and one-off run intents. Remote-target and operation checks happen before claim.
- Result replies validate protocol/request identity, operation resource identity, and command ordinal before transitioning to `accepted`. Definite bridge rejection and before-send transport failures become `not_delivered`; after-send/transport-uncertain or malformed replies become `uncertain`.
- Existing ordered eligibility blocks later same-session submit ordinals until the prior intent is reconciled or proven not delivered. Event mirroring and terminal-output reconciliation remain later phases.
