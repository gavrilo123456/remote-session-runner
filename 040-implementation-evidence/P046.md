## Planned deliverable and gates

1. Add an owner-only Unix listener with a 0700 parent requirement and mode-0600 socket, rejecting an existing socket path rather than unlinking it.
2. Add private create/read session routes that bound request bytes before JSON parsing, map validated requests into the existing `execution.Service`, enforce remote-only runnerd targets, preserve controller checks, and return authoritative snapshots.
3. Adapt the existing Linux host-process runtime to the shared `SessionRuntime` interface with a fresh runtime generation and no replacement execution core.
4. Wire the `runnerd` command to the Linux config, SQLite authority, environment registry, runtime adapter, and private server. Public HTTPS, SSH bridge, commands/events, and shutdown/restart behavior remain later phases.
5. Run the focused Mac private API/socket gate, the real Ubuntu Linux create/read gate proving the Bash UID is `ubuntu`, and the existing regression/full/race/vet/smoke/format/diff gates after the Git handoff.

## Unresolved assumptions

- The private socket accepts both `/internal/v1/sessions` and the shared `/v1/sessions` route spelling over Unix transport so later bridge/client adapters can select their documented path without a second service core. No public TCP/HTTPS listener is added in this phase.
- P046 requires caller-supplied stable `session_id`, `idempotency_key`, and controller identity; deriving ingress-specific IDs or authenticated mTLS principals belongs to later adapters.

## Implementation results

**Status: PASS**

- Added `src/internal/runnerd` with an owner-only Unix HTTP server. It requires an owner-only parent, creates a mode-0600 socket, rejects a pre-existing socket path, bounds request bodies before decoding, and removes only its own socket on close.
- Added private create/read session routes at `/internal/v1/sessions` (with the shared `/v1/sessions` Unix-transport spelling accepted as an alias). The handler validates target, controller, source, limits, and isolation inputs, enforces remote-only runnerd targets, computes the shared canonical idempotency hash, and calls the existing `execution.Service` for authoritative acceptance/read/controller checks.
- Added `LinuxSessionRuntime`, the sole P046 adapter bridge from `LinuxProcessAdapter` to `execution.SessionRuntime`. It records a fresh runtime generation, carries Linux source preparation through the existing adapter, starts one persistent Bash as `ubuntu`, and preserves the agent beyond the HTTP request context so the session outlives create-response cancellation.
- Wired `src/cmd/runnerd/main.go` to load the owner-only Linux config, open the authority SQLite store, build the environment registry and Linux runtime, and serve the private socket. Public HTTPS, SSH bridge, command/event routes, and signal-driven shutdown remain later phases.
