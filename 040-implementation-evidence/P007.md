## P007 scope and gate

Add shared domain validation for serialized request/frame size (1 MiB) and valid UTF-8 script byte size (128 KiB). Measure scripts in UTF-8 bytes, not Unicode code points. The serialized validator accepts raw bytes so HTTP/request callers can run it before JSON decoding; the frame validator uses the same ceiling before frame decoding. These are validation helpers only: P007 must not add a transport, database, execution service, or alternate acceptance path.

Add focused tests for below/at/above each boundary, multibyte UTF-8 at and above the byte limit, invalid UTF-8, and a rejected raw oversized byte sequence that need not be valid JSON. Replace the P003 contract test's duplicate byte-count logic with these shared helpers so the already-published API contract checks exercise the common limits. Add an acceptance tripwire in the hermetic tests: rejected request or script validation must leave counters for intent creation, event append, and runtime start untouched. The tripwire is a unit harness, **not** a database or Runner application integration test; the actual store/event/runtime negative cases remain owned by the phases that add those components.
