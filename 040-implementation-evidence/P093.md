- **Runtime regression found and fixed:** the first full `make test` run exposed a P035 contract defect in `PersistentShell.CancelCurrentCommand`: when process completion arrived without a proven stop boundary, it returned `Confirmed:false` with no error and left the shell reusable. The implementation now marks the shell lost and returns `ErrPersistentShellLost` in every unconfirmed completion/settle path. The P035 test now accepts a clean confirmed result or requires the lost error for an unconfirmed result, then verifies the lost shell cannot run another command. This is a necessary cross-phase repair discovered by P093's required full-suite gate.
