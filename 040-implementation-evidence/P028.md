## Planned deliverable and gates

1. Add a retention migration and durable command metadata field for an expired output boundary.
2. Expire terminal command event payloads at 30 days while retaining command metadata and returning `retention_expired` with no event payloads.
3. Remove expired idempotency bindings at 90 days.
4. Remove terminal job, command, and session metadata after 90 days only when cleanup and command-stop boundaries are confirmed.
5. Prove that unresolved session reservations and command slots pin live parent metadata beyond 90 days, then allow cleanup and GC after confirmation.

## Implementation results
