## Implementation

- Added a pre-mutation control guard to the remote driver. A recorded cancel suppresses an unclaimed submit; a recorded close suppresses unclaimed submit and create intents. Those local predecessors transition to `not_delivered`, and later ordered work can proceed without a target mutation or invented remote state.
- A cancel or close intent whose predecessor is already proven `not_delivered` is itself proven `not_delivered` without sending a bridge call. If the predecessor is `dispatching`, `uncertain`, `accepted`, or `reconciled`, the stable cancel/close mutation remains eligible for target reconciliation.
- Uncertain create and submit outcomes are preserved. Stable close/cancel operations can be delivered against their original session/command IDs, while a resource-not-found or transport result does not rewrite the uncertain predecessor.
- Added focused P073 tests for cancel-before-submit, close-before-create/submit, uncertain submit plus cancel, and uncertain create plus close.
