## Planned deliverable and gates

1. Add private submit/read command routes on the existing Unix server, with canonical request hashing and the existing authority idempotency transaction.
2. Execute only the exact script bytes accepted by the shared service through the existing persistent Linux Bash adapter; do not add a second command engine.
3. Add controller-checked durable replay and follow event output, preserving raw output bytes as base64 and ordered event cursors.
4. Prove duplicate submit across a fresh service/server instance returns the retained command and script fingerprint without a second runtime call.
5. Run focused Mac P047 tests, full Mac regression/vet/build/smoke/race/format/diff gates, then the synchronized Ubuntu real-host submit/read/events test.

## Unresolved assumptions

- P047 private submit requires caller-supplied stable `command_id`, `session_id`, `idempotency_key`, and controller identity; the later SSH bridge derives the authenticated controller server-side and does not trust payload controller fields.
- The P047 HTTP handler returns a completed command snapshot because the shared service currently drives the already accepted command through its runtime before returning. Later ingress/queue phases retain the same authority transaction and add asynchronous intent semantics where specified.

## Implementation results

**Status: PASS**

- Added private command submit/read/event routes at `/internal/v1/sessions/{session_id}/commands`, `/internal/v1/commands/{command_id}`, and `/internal/v1/commands/{command_id}/events`, with `/v1/...` Unix-transport aliases.
- Submit validates the path/body identity, controller, UTF-8 script, timeout and intent values, computes the shared canonical mutation hash, and calls the existing authority-backed `execution.Service` rather than adding a second command engine.
- Added controller-checked command reads and durable event replay/subscription helpers. Event output is ordered NDJSON; stdout/stderr payloads are base64 encoded so raw bytes survive transport without being interpreted as text.
- Extended the Linux runtime bridge to source the exact durable `Command.ScriptBytes` through the existing persistent Bash adapter, preserving the `ubuntu` execution identity and the long-lived agent context.
- Added a restart test proving duplicate submit returns the retained command and script fingerprint without a second runtime call after a fresh server/service instance.
