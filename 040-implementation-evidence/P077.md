## Implementation

- Added schema migration `0013_remote_job_projections` and `store.RemoteJobProjection` persistence. Job views keep stable job/session/command identity, job/command/output/teardown status, target/controller/environment/source/capabilities, `observed_at`, and `is_stale` in a table separate from local execution authority.
- Added monotonic remote job upsert/read/stale operations with immutable identity checks and older-observation suppression. Rich `run`/resume replies are projected by the Dispatcher; sparse acceptance envelopes remain valid without inventing job state.
- Extended the Mac API job read to return `view: projection` for accepted/reconciled remote jobs when a durable projection exists; unaccepted or unprojected jobs remain local-intent views.
- Added Mac mirrored remote event replay and follow. `GET /v1/commands/{id}/events` reads only durable `local_remote_events` after the supplied cursor, emits the same ordered base64 event shape, polls the local mirror for follow, and stops at a mirrored terminal event. It never opens SSH or treats a missing remote event as complete output.
- Added focused store, Dispatcher, and local API fixtures for job projection identity/monotonicity/staleness, mirrored replay cursor behavior, terminal follow delivery, and remote job read projection.
