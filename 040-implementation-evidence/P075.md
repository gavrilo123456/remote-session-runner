## Implementation

- Added schema migration `0011_remote_event_gaps` and `AuthorityStore.RecordRemoteEventGap`/`GetRemoteEventGap`. A gap records the available contiguous prefix, missing range, independently confirmed terminal sequence/state, and `remote_event_gap` incomplete-output reason. It is idempotent for the same confirmation, rejects conflicting confirmations, and never advances `local_remote_event_cursors`.
- Extended remote event mirroring to parse a bounded `event_history_unavailable` prefix, issue a separate `get_command` read, require the same command identity plus a terminal command state and a final sequence beyond the available prefix, persist the gap, and reconcile the already accepted submit intent. The cursor and missing events remain unchanged.
- Later same-session ordinals unblock only after the accepted predecessor becomes `reconciled` through that confirmed gap path. An unknown gap, a nonterminal/invalid terminal read, a transport error, or a recorded/uncertain predecessor leaves the predecessor unsettled and later commands blocked. Existing P073 proven-not-delivered cancellation behavior remains unchanged.
- Added focused store and dispatcher fixtures for gap persistence/idempotency/conflict, cursor preservation, confirmed terminal gap unblocking, unknown gap blocking, and nonterminal confirmation blocking.
