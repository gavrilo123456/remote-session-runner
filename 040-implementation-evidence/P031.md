## Planned deliverable and gates

1. Start exactly one Bash process with no profile/startup files, private session workspace, and reserved descriptor 4 for control frames.
2. Materialize each accepted script as a mode-0600 file, write and `Sync` it before sourcing, and remove per-command files after the result is captured.
3. Source the file inside the existing shell so exported variables, functions, current directory, and `umask` survive the next command; serialize commands and never replace the shell after it exits.
4. Exercise two-command R-01 state preservation, real nonzero completion, private workspace/file lifecycle, shell quoting, and close/no-reuse behavior.

Required gates: focused P031 tests, store/execution regression tests, full `make test`, `make vet`, `make smoke`, selected-toolchain formatting and `git diff --check`, and the full race suite. No host-dependent SSH, HTTPS, mTLS, or Runner application test is assigned to P031. P143's software-crash-only durability path still requires explicit approval if physical power-cut tests are unavailable.
