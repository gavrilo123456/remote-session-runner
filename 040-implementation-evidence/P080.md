## Implementation

- Added `src/internal/localapi/p080_test.go` with a cross-component hermetic fixture. A local one-off is accepted through the Unix API, the API/store are stopped and reopened before Router delivery, then `dispatcher.LocalDriver` sends only identity/hash to owner-only `runner-locald`, which runs the shared `execution.Service` job coordinator and executor.
- The fixture verifies the exact script bytes in the durable local intent, job row, and command row after the restart barriers, and records exactly one runtime execution. It then restarts locald/executor and replays the same identity-only acceptance; the completed job is returned without a second runtime call.
- The corruption fixture changes only the persisted local-intent script bytes after API receipt. Store reload returns `ErrLocalIntentPayloadCorrupt`; Router eligibility fails before calling its target acceptor, so no changed, empty, or alternate script reaches the executor.
- The test runtime is a tripwire fake that records every script received by `ExecuteCommand`. It runs only in the hermetic Mac-side suite; no Runner process is started on Ubuntu and no public HTTPS/mTLS or Linux account claim is made.
