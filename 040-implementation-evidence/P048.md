## Planned deliverable and gates

1. Add private cancel and close mutations that use the shared service, stable idempotency hashes, controller checks, and existing Linux runtime control; no handler-side shell logic.
2. Add private one-off run and job read routes using the durable job coordinator, stable job/session/command IDs, canonical payload, and exact script bytes.
3. Add fake restart/idempotency assertions and a real Ubuntu private API gate proving cancel/close/run/get-job behavior through the Linux host runtime.
4. Run focused Mac P048 tests, full Mac regression/vet/build/smoke/race/format/diff gates, then the synchronized Ubuntu host gate.

## Unresolved assumptions

- Private mutation bodies carry stable IDs, `idempotency_key`, and controller identity because the owner-only Unix socket has no certificate principal; later SSH/mTLS adapters authenticate the controller server-side.
- Private close accepts a `policy` string and hashes `operation`, `session_id`, and `policy`, matching the shared `CloseSessionRequest` contract.
- Private run accepts the full immutable run payload and allocates stable `job_id`, `session_id`, and `command_id`; the shared service remains the only execution core.

## Implementation results
