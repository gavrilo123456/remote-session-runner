## Planned deliverable and gates

- Add `src/internal/localapi` owner-only AF_UNIX HTTP/JSON handling for `POST /v1/sessions` and `GET /v1/sessions/{session_id}`.
- Accept both selected local and remote execution targets as Mac-local intents with `acceptance_scope: local_intent` and `known_state.delivery_state: recorded`; do not create authoritative execution-session rows.
- Use the existing durable local-intent store and canonical request hash/idempotency binding. Read responses must expose a `local_intent` view without fabricating session state.
- Reject malformed/unknown request fields, invalid target/source shapes, missing idempotency key, and requests over 1 MiB before any intent insertion. The handler package must have no SSH, transport, or remote runtime dependency.
- Focused gate: P063 oversize create leaves zero local intents; early-create/read contract and local handler no-SSH tripwire subset.

P143 remains a future explicit approval gate if physical power-cut testing is unavailable; this phase cannot infer that approval or durability result.

## Implementation result

- Added `src/internal/localapi/server.go` with an owner-only Unix socket server at the configured socket path. The server validates the owner-only parent and `0600` socket, accepts only `POST /v1/sessions` and `GET /v1/sessions/{session_id}`, and has no SSH, transport, dispatcher, or runtime dependency.
- `POST /v1/sessions` reads at most the shared 1 MiB ceiling before JSON decoding. It rejects missing idempotency keys, malformed/unknown fields, invalid target/source combinations, and oversize canonical requests before calling SQLite. It generates stable session/intent IDs, canonicalizes and hashes the request, and records only a `create_session` local intent through the existing durable store.
- Both `(local, mac-workstation)` and `(remote, linux-host)` are accepted by the Mac ingress. Both return `acceptance_scope: local_intent` and `known_state.delivery_state: recorded`; no `exec_sessions` authority row is created. Remote `local_worktree` requests are rejected before insertion.
- `GET /v1/sessions/{session_id}` resolves the stable session ID through the local intent store and returns `view: local_intent`, `is_stale: false`, controller, target, source, delivery state, and observation time. It never fabricates `session_state` or other target-authoritative fields.
- Added `GetLocalIntentByResource` to the store for controller-scoped stable-resource lookup.
- Added focused P063 tests for both target kinds, owner-only modes, oversize-before-insert, idempotency replay/conflict, remote local-worktree denial, no authoritative session insertion, and a source-level no-SSH import tripwire.
