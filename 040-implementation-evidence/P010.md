## Scope and selected configuration inputs

P010 adds a strict owner-restricted YAML loader, a validated explicit environment registry backed by `domain.NewEnvironment`, path-only secret references, selected defaults, and rejection of unknown security-relevant fields. - Both environments start from P006 `DefaultServiceLimits`: 20 sessions, 4 running commands, 1 MiB serialized requests, 128 KiB scripts, 30-minute command/idle timeouts, 4-hour session lifetime, 100 MiB output, 1 MiB subscriber buffer, 16 MiB persistence queue, 90-day metadata/idempotency retention, and 30-day output retention.
- Mac service root `/Users/tomasz.walczuk/Library/Application Support/RemoteSessionRunner`; Linux service root `/home/ubuntu/.local/share/remote-session-runner`. The selected `secrets/` paths in the decision note remain references only; P010 never reads secret file contents.

Implementation choices for this config contract: use YAML v3.0.1, one document per file, typed fields with `KnownFields(true)`, reject duplicate keys/aliases/custom tags/trailing documents, and cap config input at 1 MiB. File loading will require a regular non-symlink file owned by the effective process UID with no group/other permissions. A secret reference is an absolute path beneath that host's selected `secrets/` directory; it is never inlined or opened by this phase. Missing per-environment service-limit values inherit the P006 selected defaults. These choices define the parser boundary and do not imply deployment readiness.
