- The first replacement runnerd did not start because SIGTERM left a stale Unix socket. Its log reported `private runnerd socket path is invalid: socket path already exists as S---------`. - Earlier runs also exposed an incomplete runnerd `get_command` response. The read response now reports the stored session's execution context and immutable environment policy; the actual-host run then passed.

These failed attempts are not counted as passes. Only the final run above satisfies P-MBX-01.
